# 热换动作通道时的窗口 LayerNorm 与姿态衔接

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

通道图按生效时刻选择，其中 channels 从输入位置映射到物理身份。时刻内计算 z=x+skip，仅 valid=true 的元素参与总体方差和均值。输出 y=(z-mean)/sqrt(variance+epsilon)*gamma+beta。每种骨架的输出量化采用最近整数、恰好居中时取偶数，夹至 [-127,127]，比例见骨架声明。断点按时刻、骨架身份与单位比例追踪。无效通道不参与计算。工作空间计入尚未领取的归一化结果与本地计算缓冲，不计调用方输入。时刻单位为帧序号。 样本时间决定通道图。同一套物理关节在切换后可以使用不同骨架契约，且不同有效子集不等于换骨架。对已领取范围的补发只产生冲突；同一补发仍可以修改未领取且使用相同时刻的新窗口。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。ingest 给出首次传送的记录下标范围，resend 引用一条补发记录。consume 指定按帧编号给出的半开区间。
