# 端侧手语编码器的正交群掩码变换与手部镜像

这里的坐标姿态和训练字典是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

channels 的维度短轴为 [x,y]，每个关节有 x/y 一对。rot90 在列向量上是 (-y,x)，mirror 是 (-x,y) 并按 swaps 配对关节，连续组合按调用者给的先后顺序。sourceMask 定义于采集坐标，应用姿态时随通道移动。每种表示按 bases 的列子空间定义。每 check group 内要么完整保留，要么报告不能稳定求解。reference 是对可见通道作带权最小二乘；基取数支持近相关时要按 singularFloor 判数值秩。loss 给低维上游梯度，回传是固定当前可用表示和当前掩码下的线性伴随，不对离散可用性判定求导。可比较重构及反向，基变换自由仅在登记过同一输出表示时可用。对 sizeSpec 的压力包，budget 包含私有词典副本、投影和临时张量，样本数量变化不放宽 budget。rebuildsLimit 在转置相同掩码和物理旋转映射一致的批处理中按实际数值分解计。 组由注册顺序排列，组之间允许相关。候选可用组和允许的低维空间按依次纳入后仍满足数值秩、且已登记组完整的规则确定。采集姿态同时定义关节映射与坐标轴映射，较严格的 consumer 只接受前两组完整的输出。每组误差按其重建在观察域的实际残差，未观测不计。 采集旋转应用到带权的观测体系时，每个 x/y 权值随其轴和关节转移。跨新旧字典的注册比较以可见域内重建空间、共同输出子空间和实际扰动效果为准，差超过 relativeTol 的表示不得接续。

## 取数

`inputs/hand-features.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。handBasis(dictionary) 返回展平行主序字典，其中 0 与 1 为两次模型字典，handBatch(frame) 给按关节成对排序的坐标。
